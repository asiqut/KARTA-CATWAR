# Карты

Каждая карта хранится отдельным JSON-файлом в этой папке. Редактор скачивает карту через кнопку «Скачать карту», после чего файл нужно загрузить сюда через GitHub.

Список вкладок просмотра находится в `maps.json`. Чтобы добавить карту, загрузите её JSON-файл в эту папку и добавьте в массив `maps` объект с уникальным `id`, названием вкладки `name` и именем файла `file`.
